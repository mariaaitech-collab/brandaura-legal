# BrandAura Legal
> The public Terms of Service and Privacy Policy for the BrandAura app.

![language](https://img.shields.io/badge/language-HTML-4338CA?style=flat-square&logo=html5&logoColor=white) ![framework](https://img.shields.io/badge/framework-GitHub_Pages-4338CA?style=flat-square&logo=github&logoColor=white) ![license](https://img.shields.io/badge/license-MIT-6366F1?style=flat-square) ![status](https://img.shields.io/badge/status-live-818CF8?style=flat-square)

## Overview
App stores and platform developer programmes, such as TikTok for Developers, require an app to publish its legal terms at a public URL. This repo hosts BrandAura's Terms of Service and Privacy Policy as a small, fast static site.

**Live:** https://mariaaitech-collab.github.io/brandaura-legal/

## Features
- Landing page linking to both legal documents
- Terms of Service page
- Privacy Policy page
- Responsive, readable layout with no frameworks or build step
- TikTok for Developers site verification

## Getting Started
No build step. Clone and open `index.html` in a browser:

```bash
git clone https://github.com/mariaaitech-collab/brandaura-legal.git
```

The site is served by GitHub Pages from the `main` branch.
